🏆 OWASP CI/CD InfoSec Risks / часть 2

Салюты,

Давай посмотрим дальше на риски CI/CD,

Вот тут мы разобрали пример и я привел в карусели описание для первых 5.

Оставшиеся риски включают из себя гигиену секретов до логирования.

В карусели описания, а ниже разберём несколько блоков с реальным кейсом из боя

SEC-7 Insecure System Configuration

• Непропатченные CVE - Self-hosted раннеры и билд-серверы с известными дырами

• Дефолтные креды и открытые админки - панель управления CI торчит в интернет без MFA

• Избыточная сеть - раннер видит весь внутренний контур, а не только то, что нужно сборке

Кейс

Январь 2024, Jenkins CVE-2024-23897: баг в CLI (args4j раскрывал @file) давал чтение произвольных файлов на контроллере — включая ключи и credentials.xml — с эскалацией до RCE

Реко

• CIS Benchmark для SCM/CI/registry, отключить анонимный доступ

• Не выставлять админки CI в интернет — только через VPN/bastion + MFA

• Раннеры в изолированном сегменте, минимум сетевого доступа

SEC-9 Improper Artifact Integrity Validation

• Неподписанные коммиты и артефакты

• Скачивание без проверки - инсталляторы и тулы тянутся в пайплайн без сверки checksum

• Деплой по тегу - :latest вместо digest

• Нет SBOM и provenance, то есть не видно, из чего и как собран артефакт

Кейс

Декабрь 2020, SolarWinds (SUNBURST): атакующие внедрились в сам процесс сборки Orion и подложили бэкдор в билд. Вредонос попал в официально подписанное обновление и разъехался примерно на 18к клиентов, включая госорганы США. Код в репозитории был чист — скомпрометирован был build, а артефакт никто не сверял с источником

Реко

• Подпись коммитов и артефактов (Sigstore/ cosign), проверка перед деплоем

• Верификация checksum всех скачиваемых в пайплайн тулов

• Деплой образа строго по digest (@sha256:...), не по тегу

• SBOM (CycloneDX) и provenance (SLSA)

• Изоляция и контроль целостности build-среды

Как работает?

# keyless cosign

cosign sign &#036;IMG@sha256:<digest>

cosign verify --certificate-identity=... &#036;IMG@sha256:<digest>

# деплой строго по digest (на кубе), не по :latest

kubectl set image deploy/app app=&#036;IMG@sha256:<digest>
