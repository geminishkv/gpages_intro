🛠 Understand-Anything AppSec knowledge graph

Salute,

Today I want to share information about an interesting project that allows you to analyze the project in an understandable picture for you. So, this is Understand-Anything - a plugin for Claude Code, which, through LLM, builds an interactive knowledge graph: nodes, connections, architectural layers and a guide tour of the project’s code base.

Basically, this is a cool feature where you can install a plugin, run it and get this:

• Repo scan with identification of languages, frameworks, imports

• Semantic batches

• Collect a graph: nodes (files, functions, classes, configs, services, schemas) and connections (imports, calls, depends_on, deploys, tested_by)

• Lays out the architectural layers, builds a tour guide (see cropped image in .mmd), that is, the output is knowledge-graph.json, from which you can assemble the High level Architecture of the entire system

• Brings up a local dashboard for visualization and navigation

Why AppSec?

• Quick inspection of the codebase - in minutes you see entry points, data flows, external integrations and all external calls without manual grep

• Ready onboarding for a new person on security review

• .understandignore - you immediately throw out secrets, lock files and garbage from the analysis (well, we know that it’s better to stick it in Vault)

• knowledge-graph.json is committed to the repo - any subsequent auditor receives the map immediately after git clone

• Front and back HTTP connections do not appear in the graph: sees static imports, not network calls

Teams:

# Node ≥22 and pnpm, then build the kernel

npm install -g pnpm

cd ~/.understand-anything/repo/understand-anything-plugin

pnpm install && pnpm --filter @understand-anything/core build

# Build a graph

/understand --language en

# Raise an interactive dashboard

/understand-dashboard

# flags:

--full (full rebuild)

--review (LLM review of the graph)

Total:

• Not a silver bullet, but as a map of the area for an unfamiliar code - very cheerful

• Graph and .mmd for architecture or security is the best thing when you need to get into it right away, and then, in the old fashioned way, it’s hands and head

• Attack surface mapping from scratch (API endpoints, webhooks, queues), external integrations, public vs internal interfaces.

• Scope for pentesting. The graph immediately shows what to test: all external API calls, all incoming data handlers, all places where user input enters the system

• Literally guided walkthrough of architecture

• See the boundaries of trust
