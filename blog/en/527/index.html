🛠 OWASP Agentic Skills

OWASP has released the first agent skills security framework. Covers OpenClaw (SKILL.md), Claude Code (skill.json), Cursor/ Codex (manifest.json), VS Code (package.json)

Model

MCP determines what instruments are available, and skill determines how to orchestrate them. This behavioral layer is not protected by either model or protocol.

- The repository configs have become execution layer: CVE-2025-59536 (CVSS 8.7) in Claude Code, in fact this is pre-consent code execution. It looks like this: opening a project in the agent, config executes the shell, exfiltrating API keys

- SKILL.md as an RCE vector: lines in YAML instruct the agent to read ~/.ssh/id_rsa and exfiltrate, which the agent executes as trusted

- Lethal Trifecta - criticality condition

1. Private data (SSH, API keys, wallets)

2. Untrusted content (SKILL.md, MEMORY.md, email)

3. External egress (network, webhooks, curl)

Problematic Tier

- AST05: payload is pulled from attacker-controlled URL at runtime - bypasses install-time scan by design

- AST07 SkillJacking: dangling dependencies are hijacked, where only hash pinning saves

- AST08: padding, logic in binaries, prompt-injection versus LLM. Pattern-matching is useless

Universal Skill Format

permissions:

files:

deny_write: [SOUL.md, MEMORY.md, AGENTS.md] # closes persistent backdoor

network:

allow: [api.example.com] # closes over-permission

deny: "*"

shell: false

signature: "ed25519:..." # Merkle-root verification

content_hash: "sha256:..." # Merkle-root verification

Total (my God, we didn’t know - you give the agent access to files, the network and the shell - you create exactly the attack surface that this Top 10 is about)

- Execution layer in configs: SKILL.md, settings.json are executed, not read - CVE-2025-59536

- pre-consent RCE via repo cloning

- scanners cost an hour, we need a behavioral pipeline

- Base: least privilege, sandbox, hash pinning, co-sign as an extra (we’re talking about mechanics, not tools)
