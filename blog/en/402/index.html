The supply chain attack compromised npm packages in the Red Hat ecosystem, distributing a new variant of the Shai-Hulud malware, dubbed Miasma.

The incident was discovered by Aikido and OX Security (1 and 2), which identified dozens of versions of packages containing backdoors with malware designed to steal developer credentials, secrets from cloud services, SSH keys, CI/CD tokens and other sensitive information.

According to Aikido, hacked packages are downloaded approximately 117,000 times a week. As Red Hat noted, the affected packages were removed after it became aware of the incident.

The compromised packages are intended exclusively for internal development; the malicious code was not distributed to clients through the console.redhat.com system.

The investigation into the incident is ongoing, but there are no preliminary findings of any impact on customer or partner environments or Red Hat production systems.

According to Aikido, attackers apparently hacked into a Red Hat employee's GitHub account and used it to directly push malicious commits to multiple repositories.

The changes introduced added a GitHub Actions workflow and a script that used the npm publishing engine to release backdoor packages.

When the workflow started, it would install Bun and run the _index.js command, passing it a list of target packages via the OIDC_PACKAGES environment variable.

The script uses id-token: write permission to request a short-lived OIDC token from GitHub, then uses that token to directly authenticate with the trusted npm publish endpoint and publish versions of each package on the backdoor list.

The compromised packages contained a malicious pre-installation script that automatically executed a heavily obfuscated malicious index.js file when developers installed the packages.

The payload size in the index.js file was approximately 4.2 MB and was used to steal GitHub Actions secrets, AWS credentials, Google Cloud and Docker credentials, Azure service principal, HashiCorp Vault tokens, Kubernetes service record, npm and PyPI publish, SSH and GPG keys, and .env files.

Researchers claim that the malware used in the Red Hat hack has many similarities to Mini Shai-Hulud, but now uses the string "Miasma: The Spreading Blight" as comments in the hacked GitHub repositories.

The malware may resemble TeamPCP's Mini Shai-Hulud, but it is unclear whether the campaign was carried out by this attacker or by another who modified the source code of the leaked malware.

OX Security believes the malware retains the same credential theft functionality as Mini Shai-Hulud, but adds additional layers of obfuscation, multi-stage payload delivery mechanisms, and advanced data theft and credential harvesting functionality.

To date, 309 GitHub repositories have been compromised by Miasma malware. Those who have installed affected versions of the malware are advised to immediately update all credentials, secrets, and tokens.
